## 1. 准备：把服务跑起来（运维做一次）

```bash
# 1) 启动数据库
sudo pg_ctlcluster 16 main start

# 2) 启动服务（注意：必须用 --bin gaas-server 指定二进制）
cd gaas_topcast_base
GAAS_MASTER_PASSWORD='Master2026!' \
  cargo run -p gaas-server --bin gaas-server -- --config conf/c.toml

# 3) 看到下面这行就说明起来了
#    INFO gaas_server: gaas 基础框架 http://127.0.0.1:6080
```

要点：

1. **集群 Master 口令**（本文示例 `Master2026!`）用于「创建/备份/删除数据库」。
   它属于**平台安全职责**，与租户里的 admin 身份完全分离——admin 不能建库/删库。
   本文用环境变量 `GAAS_MASTER_PASSWORD` 静态指定，重启后仍然有效；
   若未指定，系统会随机生成并在**首次安装页 `/setup` 只显示一次**。
2. 服务只监听 `127.0.0.1:6080`，浏览器打开 <http://127.0.0.1:6080/> 即可。
3. 数据库连接配置在 `gaas_topcast_base/conf/c.toml`（本机 `127.0.0.1:5432`，
   库 `gaas_boot`）。会话签名密钥 `.sesskey` 会自动生成在配置文件同目录。

| 10 | 存续期利息股息红利（第四条第一款） | 2024-12-31 | 汇编 001 | 1,200,000 USD | 7.0984 | 8,518,080 | 1,703,616 |
| 11 | 存续期利息股息红利（第四条第一款） | 2024-12-31 | 汇编 001 | 500,000 USD | 7.0984 | 3,549,200 | 709,840 |
| 12 | 存续期利息股息红利（第四条第一款） | 2025-12-31 | 汇编 001 | 1,500,000 USD | 7.10 | 10,650,000 | 2,130,000 |

> 两条「装入」事件是**人民币计价的视同财产转让**：
> 编号 9 = 4500 万 − 1500 万 − 30 万 = 2970 万 → 税 594 万；
> 编号 14 = 2600 万 − 800 万 − 25 万 = 1775 万 → 税 355 万。
> 外币事件的人民币金额 = 原币金额 × 登记汇率。

### 9.2 为什么有些行是浅黄色？

浅黄行 = 该草稿带 `_ai_flags`（AI 推测/缺失字段标记），来源是系统的**防编造机制**：

| 层级 | 机制 | 效果 |
|---|---|---|
| L1 | 汇率必须命中登记表 | 未登记 → 删除 AI 猜的汇率并标记 |
| L2 | 金额必须能在附件原文找到数字锚点 | 找不到 → 保留但标记「⚠需核对」 |
| L3 | 带标记草稿**禁止批量一键审核** | 必须逐条打开核对 |

所以看到黄底不要慌——它表示「这里必须人看一眼」，这正是合规系统该有的样子。

![勾选无标记草稿批量审核](imgs/step31-select-clean.png)

### 11.2 情况二：草稿带 ⚠ 标记 → 系统会拦你一下

如果勾选里含有带标记的草稿，系统**拒绝**批量审核：

![批量审核被拦截](imgs/step28-flag-block.png)

> 事件 15,14,12,9 含 AI 推测/缺失字段（如汇率未登记、金额无附件依据），
> 已阻止批量审核；请逐条打开核对后再操作

这不是报错，是**护栏**。提示里的数字就是这些草稿的**事件编号**，按下面方式逐条审核：

1. 打开该事件的详情页：把申报人详情页地址末尾加上 `/events/事件编号`，
   例如 `http://127.0.0.1:6080/trusts/<申报人ID>/events/9`；
2. 页面顶部是五态进度条（草稿 → 已审核 → 已聚合计算 → 已申报 → 纳税状态），
   下方「申报人 / 事件类型 / 应纳税所得额 / 汇率 / 应纳税额」等字段可逐项核对：

![事件详情页（草稿态）](imgs/step29-event-detail-draft.png)

3. 点「**审核**」→ 确认 → 进度条第 2 步变成 ✓ 绿色，状态「已审核（待聚合）」
   并记录审核人与时间：

## 17. 常见问题（FAQ）

**Q1 登录提示「账号不存在」？**
账号栏要填**邮箱**：`admin`、`clerk1@demo.local`、`manager1@demo.local`。

**Q2 草稿里外币金额是空的／税额是 0？**
没登记汇率。到「汇率管理」按**事件日期 + 币种**登记后，用附件行的
「AI 重新解析」重新解析（单附件按钮；批量解析会跳过已解析过的附件，
以免重复累积草稿）。

**Q3 点「审核选定事件」被拦？**
选中的草稿里有带 `_ai_flags` 的（AI 推测/缺失字段）。按提示的事件编号
逐条打开事件详情页审核，或只勾选没有 ⚠ 的草稿批量审核。

**Q4 上传附件时提示「内容相同，已跳过」？**
文档库按 MD5 去重：同一份内容只存一份，重复上传只会增加一次「引用」。

**Q5缴款后台账看不到记录？**
缴款管理默认筛选「未结清」；缴清后切到「全部（含已缴清）」。

**Q6 金额显示不整齐？**
系统统一「千位分隔 + 两位小数 + 负号紧贴数字」（如 `-1,420,000.00`），
这是显示规范，不影响计算。
